# ColorLabel Component

`ColorLabel` 컴포넌트는 정보를 카테고리화하고 표시하는 데 사용되는 소규모 레이블입니다. 이는 리스트나 카드에 태그를 추가하여 콘텐츠의 종류를 빠르게 식별할 수 있도록 합니다.

## Description

`ColorLabel` 컴포넌트는 시각적 식별자 역할을 하며, 사용자가 정보를 빠르게 분류하고 이해할 수 있도록 돕습니다. <br/>
텍스트 색상만 지정하면 배경은 텍스트 생상의 투명도를 조정한 색으로 자동 지정됩니다. <br/>
내부에 Typography 컴포넌트를 포함하고 있으니 children으로 텍스트만 포함해주세요. <br/>
